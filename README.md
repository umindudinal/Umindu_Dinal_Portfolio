## 📖 Overview

This is my personal portfolio website, designed and developed to present my work as a developer in a clean, professional, and interactive way. The site includes sections for an introduction/about me, skills, projects, and contact information, allowing visitors and potential employers to quickly learn about my background and get in touch.

## ✨ Features

- 🎨 Clean, modern, and fully responsive UI
- ⚡ Fast performance with a component-based architecture
- 🧩 Reusable, well-structured React components
- 📱 Mobile-first responsive design using Tailwind CSS
- 🖥️ Dedicated sections: Home, About, Skills, Projects, Contact
- 🚀 Deployed and hosted on Netlify with continuous deployment

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/umindudinal/Umindu_Dinal_Portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Umindu_Dinal_Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   Visit `http://localhost:5173` (or the port shown in your terminal) to view the site.

### Build for Production

```bash
npm run build
```

This generates an optimized production build in the `dist/` (or `build/`) folder, ready for deployment.
